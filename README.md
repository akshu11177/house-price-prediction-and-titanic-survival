# Machine Learning Projects

## Projects Overview

This repository contains two Machine Learning assignments implemented using Python.

### 1. House Price Prediction

- **Dataset:** Kaggle – House Prices Dataset
- **Algorithm:** Linear Regression
- **Objective:** Predict house sale prices.
- **Tasks Performed:**
  - Data preprocessing
  - Model training
  - House price prediction
  - Model evaluation using R² score
  - Actual vs. predicted value visualization

### 2. Titanic Survival Prediction

- **Dataset:** Titanic Dataset (Kaggle)
- **Algorithm:** Logistic Regression
- **Objective:** Predict passenger survival.
- **Tasks Performed:**
  - Data cleaning and preprocessing
  - Handling missing values
  - Model training
  - Survival prediction
  - Model evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
