# Project Overview

This repository demonstrates two supervised machine-learning workflows:

| Assignment | Dataset | Algorithm | Main evaluation |
|---|---|---|---|
| Housing price prediction | Kaggle House Prices | Linear Regression | R², MAE, RMSE; actual-vs-predicted plot |
| Titanic survival prediction | Kaggle Titanic | Logistic Regression | Accuracy, precision, recall, F1, ROC-AUC; confusion matrix |
| Mini Project 2 | Kaggle House Prices | Linear Regression | House-price predictions and R² score |

Both workflows use train/test splits and scikit-learn preprocessing pipelines to handle missing values and categorical variables. All processing is local. See README.md for setup and dataset placement.
